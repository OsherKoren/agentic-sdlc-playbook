# Agentic SDLC Playbook

Practical workflows I can apply with coding agents across personal and work repositories.

## Playbooks

- [Code Review with AI Agents](playbooks/code-review/README.md) — review a change, verify findings, and decide what needs human attention.

To use a playbook, give your agent the link and ask it to apply the workflow within the target repository's rules. Keep project-specific evidence and findings in the target repository's approved workspace.
